# TreeSatAI aerial image tiles (renamed)

Image tiles used in a study of multimodal large language models for tree-genus interpretation of aerial imagery.

- `rgb/`: 150 tiles used in the pilot study.
- `formal/rgb/`: 1,019 tiles used in the main experiment.
- All tiles are true-colour PNG, 304 × 304 px, 0.2 m ground resolution.
- File names are random IDs and carry no label information.

## Source and licence

Derived from the TreeSatAI Benchmark Archive (Zenodo record 6780578), licensed under CC BY 4.0.
Changes: a subset of tiles, rendered from the 4-band GeoTIFFs (NIR, R, G, B) to true colour with one shared 0.5–99.5 % linear stretch per band, and renamed.

Ahlswede, S., Schulz, C., Gava, C., Helber, P., Bischke, B., Förster, M., Arias, F., Hees, J., Demir, B., Kleinschmit, B. (2023).
TreeSatAI Benchmark Archive: a multi-sensor, multi-label dataset for tree species classification in remote sensing.
Earth System Science Data, 15, 681–695.
